[ SETUP · 直連模式 ]

這個頁面不是由本機伺服器提供,需要你的 Claude OAuth access token 才能直接向 Anthropic API 查詢用量。

token 位置:~/.claude/.credentials.json → claudeAiOauth.accessToken。只會存在這台瀏覽器的 localStorage,不會傳到其他地方。

[ GUIDE · 改用本機伺服器 ]

瀏覽器的 CORS 政策擋下了對 Anthropic API 的直接請求(這是 API 端的限制,不是 token 的問題)。改用本機伺服器模式最可靠:

node usage-dashboard.js --serve

然後打開 http://localhost:8787 — 伺服器會自動讀取本機的 Claude Code 憑證,免貼 token。

usage-dashboard.js 就在這個 repo 的根目錄,需要 Node.js 18+。
